# Analytics Dashboard

Source: https://docs.cofounder.co/guide/analytics-dashboard
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Keep the numbers you watch on the Analytics page's Custom tab, as one report file your agent and you both edit.

The Analytics page's Custom tab is your company's dashboard. It is one
analytics report, `marketing/reports/dashboard.md` in the Library, drawn as a
grid: its `chart` blocks in file order, under its Markdown headings as section
titles. Your agent builds and changes it the way it saves any report, and you
add charts to it from your reports with **Pin to dashboard**.

Saving the dashboard needs a company admin. Any member can read it.
