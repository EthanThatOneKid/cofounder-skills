# Database

Source: https://docs.cofounder.co/guide/database
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Query your app's database, ship schema changes and functions, try changes on a branch, set up social sign-in, and move files in and out of storage.

Your app runs on a Supabase database that Cofounder manages. Your agent
queries it, changes its schema, deploys functions, and manages files, all
through your Cofounder login. You never handle database passwords or keys.

Your agent works on the company's default database and on production unless
you name another database or a branch.
