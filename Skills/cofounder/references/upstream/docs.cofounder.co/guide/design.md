# Design

Source: https://docs.cofounder.co/guide/design
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Copy a website's colors, fonts, and components into a design system you can reuse.

Give your agent a website, and it records that site's design system so new
sites, assets, and campaigns match it. The design system covers colors,
typography, surfaces, components, and layout.
