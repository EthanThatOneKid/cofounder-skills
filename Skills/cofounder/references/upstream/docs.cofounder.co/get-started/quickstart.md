# Quickstart

Source: https://docs.cofounder.co/get-started/quickstart
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Go from a connected agent to a set-up company with its first task, in four prompts.

Go from a new account to an agent working on your company. First,
[connect your agent](/get-started/connect-an-agent) through MCP or the
CLI. Each step below is something you say to your agent, followed by the MCP
tool and CLI command it uses, and the API route for your own scripts.
