# Connect an Agent

Source: https://docs.cofounder.co/get-started/connect-an-agent
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Add CofounderOS to Claude, Claude Code, Codex, ChatGPT, Cursor, or any coding agent through MCP or the cofounder CLI, then sign in.

Connect through MCP if your agent runs in Claude, ChatGPT, Codex, Cursor, or
VS Code. Connect through the CLI if your agent runs commands in a terminal,
or for scripts and CI. Both give your agent the same tools, and you can use
both.

Your agent can use Cofounder free while it sets up your company. After
setup, using Cofounder from your own agent needs the company's $40/month
subscription. See [Billing](/guide/watch-it-run#billing).

On web and mobile, your agent edits files and runs code in a Cofounder
sandbox. On desktop, it can use a sandbox or the terminal in your desktop app.
Your ChatGPT plan and workspace must support the Cofounder connection.

The options below go from least to most work. Use the first one your agent
supports.
