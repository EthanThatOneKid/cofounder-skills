# Steps Your Agent Hands You

Source: https://docs.cofounder.co/dashboard/handoffs
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Finish the browser steps your agent sends you: approving access, sharing GitHub repositories, connecting Stripe, and checking out.

Some steps need you in a browser: signing in, granting access, or paying.
Your agent sends a link to the dashboard, you finish the step there, and
you go back to your agent.
