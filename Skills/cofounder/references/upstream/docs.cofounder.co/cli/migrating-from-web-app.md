# Migrating from the Web App

Source: https://docs.cofounder.co/cli/migrating-from-web-app
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Coming from the browser-based Cofounder — how web app concepts map to the CLI and MCP, and what carries over.

If you knew Cofounder as a browser product, this is the same account and the
same companies — the difference is who's driving. The web app put you in a
dashboard; here your agent does the work. Your companies, files,
connections, and billing carry over unchanged.
