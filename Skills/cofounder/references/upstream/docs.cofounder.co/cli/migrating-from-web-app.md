# Migrating from the Web App

Source: https://docs.cofounder.co/cli/migrating-from-web-app
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** For users of Cofounder 2 or Cofounder Canvas: how web app concepts map to the CLI and MCP, and what carries over.

If you used Cofounder 2 or Cofounder Canvas, you can continue with the same
account and companies through the CLI and MCP. The difference is who's driving.
The web app put you in a dashboard; here your agent does the work. Your companies, files,
connections, and billing carry over unchanged.
