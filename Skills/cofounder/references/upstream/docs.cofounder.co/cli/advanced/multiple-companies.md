# Multiple Companies

Source: https://docs.cofounder.co/cli/advanced/multiple-companies
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Run more than one company under one account — active selection, per-command scoping, and token binding.

One Cofounder account can run many companies, and everything — knowledge,
connections, resources, events, billing — stays scoped to one of them. So
the only real question is which company a command is aimed at.
