# Multiple Companies

Source: https://docs.cofounder.co/cli/advanced/multiple-companies
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Run several companies from one account: set the active company, aim one command at another, and keep each key on its own company.

One Cofounder account can run many companies. Knowledge, connections,
resources, events, and billing each belong to one company, so every command
has to target the right one.
