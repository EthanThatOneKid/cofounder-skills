# Agent Spend

Source: https://docs.cofounder.co/cli/advanced/agent-spend
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Let agents make founder-approved purchases through Link spend requests.

Company billing pays for Cofounder itself. When an agent needs to pay
someone else (a service, a merchant, an API), it asks the founder to
approve that one purchase in Link.

To pay Cofounder for its own services, see
[Pay Cofounder with MPP](/cli/advanced/mpp-payments). That guide covers credit
purchases and using the credits for a company research report.
