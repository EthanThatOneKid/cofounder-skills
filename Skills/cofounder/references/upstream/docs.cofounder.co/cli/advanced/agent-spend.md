# Agent Spend

Source: https://docs.cofounder.co/cli/advanced/agent-spend
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Let your agent pay other merchants one purchase at a time, with you approving each purchase in Link.

When your agent needs to pay someone else (a service, a merchant, an API),
it asks you to approve that one purchase in Link. Once you approve, the
agent gets a one-time card or payment token for exactly that purchase:

request → you approve in Link → one-time card or token → agent pays

You connect your Link account on the first request and approve every
purchase yourself. Money moves only when the agent pays with the approved
card or token.

Company billing pays for Cofounder itself. To buy Cofounder credits, see
[Pay Cofounder with MPP](/cli/advanced/mpp-payments), which also covers using
the credits for a company research report.
