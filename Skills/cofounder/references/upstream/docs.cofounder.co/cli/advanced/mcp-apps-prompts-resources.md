# MCP Beyond Tools

Source: https://docs.cofounder.co/cli/advanced/mcp-apps-prompts-resources
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** What the hosted MCP server serves besides tools: resources for company state and skills, prompts as slash commands, and the CRM app.

Tools are most of the MCP surface, but not all of it. Your agent can also
read resources on demand, pick up prompts as slash commands, and open a CRM
board in clients that render MCP apps.
