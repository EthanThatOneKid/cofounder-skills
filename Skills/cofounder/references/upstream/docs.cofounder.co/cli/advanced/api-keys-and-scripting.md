# API Keys and Scripting

Source: https://docs.cofounder.co/cli/advanced/api-keys-and-scripting
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Mint API keys for agents and automation, authenticate with COFOUNDER_API_TOKEN, and script the CLI with --json.

Agents, CI jobs, and scripts shouldn't depend on an interactive login.
That's what company API keys and `COFOUNDER_API_TOKEN` are for.
