# API Keys and Scripting

Source: https://docs.cofounder.co/cli/advanced/api-keys-and-scripting
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Give agents, CI jobs, and scripts their own company API key so they run without a browser login, and parse the CLI's JSON output.

A company API key lets agents, CI jobs, and scripts act for one company
without anyone signing in. Put it in `COFOUNDER_API_TOKEN` and the CLI and
API use it.
