# Create a Company

Source: https://docs.cofounder.co/cli/guide/create-a-company
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Create the company everything belongs to, select it, and invite the people who share it.

Everything in Cofounder scopes to a company (knowledge, connections,
managed resources, the roadmap, billing), so the first thing you do is make
one. One account can run several companies, and each keeps its own context
and state.
