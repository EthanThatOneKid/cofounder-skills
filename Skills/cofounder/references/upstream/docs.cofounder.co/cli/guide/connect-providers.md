# Connect Providers

Source: https://docs.cofounder.co/cli/guide/connect-providers
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Connect GitHub, Vercel, Supabase, Stripe, and other providers so the company can act on real systems.

A company can't do real work until it can touch real systems — a GitHub
repo for code, Vercel to serve it, Supabase for the database, Stripe for
money, domains for the address. You walk through each provider's auth once;
after that your agent acts on it directly.
