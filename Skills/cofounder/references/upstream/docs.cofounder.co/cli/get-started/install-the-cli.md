# Install the CLI

Source: https://docs.cofounder.co/cli/get-started/install-the-cli
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Install the cofounder binary with npm, sign in, and keep it up to date. Node.js 22 or 24 required.

The `cofounder` CLI puts the same operations in your terminal. Install it if
you want to drive Cofounder by hand, wire it into scripts and CI, or reach
the surfaces MCP doesn't cover.
