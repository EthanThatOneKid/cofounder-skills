# Install the CLI

Source: https://docs.cofounder.co/cli/get-started/install-the-cli
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Connect your agent to Cofounder MCP or install the CLI with npm. Node.js 22 or 24 required for the CLI.

The `cofounder` CLI puts the same operations in your terminal. Install it if
you want to drive Cofounder by hand, wire it into scripts and CI, or reach
the parts MCP doesn't cover.

You don't need the CLI to use Cofounder with your agent.
Follow [Connect an Agent](/cli/get-started/connect-an-agent#install-with-your-agent)
to get started.
