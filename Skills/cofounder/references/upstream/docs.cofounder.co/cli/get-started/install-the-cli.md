# Install the CLI

Source: https://docs.cofounder.co/cli/get-started/install-the-cli
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Install the Cofounder plugin for Claude or ChatGPT/Codex, or install the CLI with npm. Node.js 22 or 24 required for the CLI.

The `cofounder` CLI puts the same operations in your terminal. Install it if
you want to drive Cofounder by hand, wire it into scripts and CI, or reach
the parts MCP doesn't cover.

To use Cofounder in Claude, ChatGPT, or Codex, [install the plugin](#install-the-plugin)
for your app. You can connect your account and get started without installing
the CLI.
