# Connect an Agent

Source: https://docs.cofounder.co/cli/get-started/connect-an-agent
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Point any MCP-compatible agent at Cofounder's hosted MCP server; no CLI install required. Covers Claude Code, Codex, Cursor, and other clients.

Cofounder runs a hosted MCP server, and your agent talks to it directly:

```text
https://api.superoptimizers.cofounder.co/mcp
```

Point a compatible client at that URL and it gets the full tool surface:
roughly 340 tools covering companies, knowledge, providers, deploys,
communication, and operations. No CLI install, no local process to babysit.
These are the same operations the CLI and API expose.
