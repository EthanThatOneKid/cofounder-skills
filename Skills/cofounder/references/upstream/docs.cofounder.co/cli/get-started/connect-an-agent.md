# Connect an Agent

Source: https://docs.cofounder.co/cli/get-started/connect-an-agent
Fetched from: https://docs.cofounder.co/llms-full.txt

**Description:** Add CofounderOS to Claude, Claude Code, Codex, ChatGPT, Cursor, or any coding agent through MCP or the cofounder CLI, then sign in.

Connect through MCP if your agent runs in Claude, ChatGPT, Codex, Cursor, or
VS Code. Connect through the CLI if your agent runs commands in a terminal,
or for scripts and CI. Both give your agent the same tools, and you can use
both.

The options below go from least to most work. Use the first one your agent
supports.
